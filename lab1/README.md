# Лабораторная работа №1 по курсу Теория Формальных Языков (Рефал)

## Задание варианта 2

Везде в задачах подразумевается, что строка — в алфавите латинских строчных букв, переменная — в алфавите заглавных латинских, строка окружена маркерами начала `^` и конца `$`. В некоторых задачах также встречаются скобки — это единственный вид скобок, круглые `()`. Образцы в левых и правых частях правил даются исчерпывающе: `^P1$ = ^P2$`, где `P2` не содержит свежих переменных, не входящих в `P1`. Подразумевается, что получившиеся системы переписывания строк должны быть эквивалентны системам переписывания образцов именно по модулю слов, имеющих представление `^[a-z]*$` (или `^[a-z]|)|($`, если в условии встречаются скобки).

### Из системы переписывания образцов в SRS, рефал-стиль

Даны несколько правил переписывания образцов, сохраняющих порядок переменных (области вхождения переменных в части правил слева и справа идут в одинаковом порядке), без повторных переменных слева и справа. Построить систему переписывания строк, эквивалентную этим правилам, учитывая, что из всех возможных сопоставлений строки с образцом всегда выбирается лексикографически меньшее по длинам значений переменных слева направо, и из всех применимых к строке правил всегда применяется самое верхнее.

## Идея решения

Левая часть правила разбивается на постоянные блоки и переменные: `u0 X1 u1 ... Xk uk`. Блоки `u0` и `uk` могут быть пустыми. Соседние переменные `XY` заменяются одной `Y`, так как при кратчайшем сопоставлении `X` пусто; вхождение `X` справа удаляется.

1. Заменяем `^` на `!` и запускаем каретку поиска первого правила.

2. Проверяем префикс `u0` строго от начала слова. После него ставим маркер границы.

3. Каждый внутренний блок `ui` ищем в самой ранней позиции после предыдущего маркера. Каретка сдвигается на одну букву, поэтому перекрывающиеся вхождения не теряются. Пройденные буквы — значение переменной `Xi`. После блока ставим маркер границы.

4. Суффикс `uk` должен стоять непосредственно перед `$`. Если на этом месте его нет, поиск продолжается дальше. Для `Xaba` на слове `ababa` получаем `X = ab`.

5. Если блок не найден, каретка отказа идёт влево, стирает маркеры и сохраняет исходные буквы. Дойдя до `!`, она запускает поиск следующего правила. После последнего правила переходов нет: вычисление останавливается, `^` не восстанавливается.

6. Если сопоставление удалось, идём по маркерам справа налево и собираем правую часть на месте. Значение переменной сохраняется, если она есть справа, и удаляется, если её нет. Постоянные блоки левой части удаляются, блоки правой части вставляются. Это возможно, потому что переменные не повторяются и не меняют порядок.

7. Дойдя до `!`, заменяем его на `^`. Получено чистое слово, снова проверяется первое правило.

### Пример

Правило `^XaYbZ$ = ^cXdZ$`, слово `^uaavbw$`.

1. Первое `a` найдено после `u`: `X = u`.
2. Первое `b` после него найдено после `av`: `Y = av`.
3. До `$` остаётся `Z = w`.
4. Обратный проход: сохраняем `w`, удаляем `b` и `av`, вставляем `d`, удаляем `a`, сохраняем `u`, вставляем `c`.
5. Восстанавливаем `^` и получаем `^cudw$`.

## Почему сопоставление кратчайшее

Префикс `u0` закреплён в начале, суффикс `uk` — в конце. Пусть существует сопоставление, в котором внутренний блок `ui` стоит позже самой ранней допустимой позиции. Перенесём блок в эту раннюю позицию. Остальным блокам это не мешает, тк. лишний промежуток поглотит следующая переменная. Значит, самое раннее вхождение даёт наименьшее значение `Xi`, совместимое с полным сопоставлением. Применяя это рассуждение слева направо, получаем лексикографически наименьший набор длин.

Если следующий блок не найден, более позднее вхождение предыдущего блока тоже не поможет, места справа останется меньше. Поэтому возвраты не нужны.

## Обозначения

Все символы имеют вид `@Kr:i;`, где `K` — тип, `r` — номер исходного правила с нуля, `i` — номер блока или шага. Строчных букв в них нет, поэтому правила движения по буквам их не затрагивают.

### Буквенные обозначения

`[a-z]` — любая буква исходного слова. Правило, записанное с буквой, генерируется для каждой из 26 букв.

### Маркеры

`!` — маркер начала слова на время работы (вместо `^`)

`$` — маркер конца слова

`@Mr:i;` — маркер границы после блока `ui`

### Типы кареток

`@Sr:i;` — каретка поиска блока `ui` правила `r`. Для `i = 0` проверяет префикс, для последнего блока — суффикс перед `$`

`@Dr:0;` — каретка успешного завершения сопоставления, начинает сборку

`@Rr:j;` — каретка сборки правой части, `j` — номер шага обратного прохода. Сохраняет, удаляет или вставляет фрагмент и переходит к шагу `j−1`

`@Fr:0;` — каретка отказа: идёт влево, стирает маркеры `@Mr:i;`, у `!` переключается на `@S(r+1):0;`

### Пример правил

Для `^XaY$ = ^XbY$`:

```text
^ -> !@S0:0;                  старт
@S0:0; -> @M0:0;@S0:1;        пустой префикс
@S0:1;a -> a@M0:1;@S0:2;      блок a найден
@S0:1;b -> b@S0:1;            сдвиг поиска (для каждой буквы кроме a)
@S0:1;$ -> @F0:0;$            блок a не найден
@S0:2;$ -> @M0:2;@D0:0;$      пустой суффикс, сопоставление завершено
a@F0:0; -> @F0:0;a            отказ, движение влево
@M0:1;@F0:0; -> @F0:0;        отказ, стирание маркера
!@F0:0; -> !@S1:0;            переход к следующему правилу
@D0:0; -> @R0:6;              начало сборки
a@R0:5; -> @R0:5;a            сохранение Y
a@M0:1;@R0:4; -> @R0:3;       удаление блока a
@R0:3; -> @R0:2;b             вставка b
!@R0:0; -> ^                  результат готов
```
